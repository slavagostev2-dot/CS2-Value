# CS2 Value

Public update channel for the CS2 Value project.

This repository contains versioned application update packages and the update manifest used by the Windows auto-updater.

## Current baseline

- Version: v0.22.4
- Local data, SQLite database, API keys and logs are never published here.
- Updates must preserve the local `data/` and `logs/` directories.

The project is under active development. Current focus: validated CS2 probability modelling, map/veto analysis, Pinnacle value backtesting, and later LIVE/Telegram integration.
